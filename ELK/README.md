
# Установка:
1. Загрузить директорию ELK
2. ```cd ELK&docker compose up -d```
3. В браузере открыть http://localhost:5601

Kiban`e нужнно некоторое время для запуска, 1-2 минуты в зависимости от мощности ВМ\железа

# Конфигурация не претендует на безопасность. Это самый простой конфиг, который развернет ELK для того, чтобы протестировать его в локальной сети.
